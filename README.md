# liedan.ai - Official Artist Portal

Official web ecosystem and audio streaming portal for **Liedan Solas**, Virtual AI DJ & Producer.

## Overview
- **Domain:** [https://liedan.ai](https://liedan.ai)
- **Studio:** AtomicHamsters LLC
- **Artist:** Liedan Solas (`@LiedanSolas` / `@liedansolas`)
- **Architecture:** Fast, responsive static web application with custom audio visualizer, discography streaming player, uncensored media vault, and official merch store.

## Features
- **Audio Transmissions Player:** Native HTML5 audio player streaming uncompressed 320kbps masters (*Synthetic*, *Human Seas*, *If You Wish*, *The Byline*, *Peace Upon the Snow*).
- **Visual Chronicles:** Embedded interactive YouTube video showcase synchronized with official YouTube releases.
- **The Vault (18+):** Self-hosted media vault featuring uncensored cuts (*FERAL*).
- **Official Merch:** Responsive shopping cart powered by AtomicHamsters LLC.
- **Harborlight Lore:** Deep backstory connection to the Living Canvas simulation engine and `livingstories.ai`.

## Deployment
Automated deployment to GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`) on every push to `main`.
Custom apex domain configured via `CNAME` (`liedan.ai`).
